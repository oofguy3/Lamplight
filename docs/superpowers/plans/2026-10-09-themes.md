# Themes (Twelve Themes in Six Looks) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the 50 built-in themes with twelve that pair into six looks, and replace the six-tab picker with one where a tap on a look sets the day and night theme. A Day/Night switch sits in the picker's head. Readers of a retired theme move to the nearest kept one and are offered their old colours once. New readers follow the phone's dark mode.

**Architecture:**

- A `LOOKS` table pairs the twelve ids. A shared tile renderer draws the looks, an optional pair tile and Mine into the popover (`#qLooks`, `#qMine`) and Settings (`#themeChips`).
- `selectLook(day, night)` sets the pair and shows the half on screen. The Day/Night switches call the existing `setDayNight`.
- A `RETIRED` table drives a move inside `Prefs.load` (`retireMove` before validation, `foldPair` after), and a `ThemeNotice` module offers "Keep the old colours".
- The picker is built first on today's colours: all twelve ids exist already. The table is swapped after that.

**Tech Stack:** Static HTML, CSS and ES5-style JavaScript (IIFE modules, `var`), with no build step. Tests are standalone Node 22 Playwright (Chromium) scripts in `tests/`, using `tests/lib.js`. tests/themes.js is node-only.

**Spec:** `docs/superpowers/specs/2026-10-09-themes-design.md`. Section numbers below ("§5.1") refer to it.

## Review Focus

1. **Keyboard focus after a tap.** A tap or Enter on a look can make the pair tile appear or disappear, which redraws the grid. Focus must land on the pressed tile, not on `body` (Task 4).
2. **Dutch at 320px in the contrast tone.**
   - The head row ("Thema" plus the Dag | Nacht switch) does not overflow.
   - The longest look name, "Zeelucht & Grachten", ends in an ellipsis inside its tile.
   - The sheet never scrolls sideways (Task 2).
3. **Junk in stored prefs.**
   - A `themeWas` that is a number, an array or an object missing keys loads as `null`.
   - A retired id only in `dnHold` gives no notice.
   - Load never throws (Task 6).
4. **E-ink mode on, with a retired theme saved.** The notice shows. Keep restores the originals while e-ink stays on, and the page stays black on white (Task 9).
5. **A custom theme on screen outside the pair (Auto off) at upgrade.** No fold happens, since only built-ins fold. No look tile is pressed, and the reader's custom stays on screen after the reload (Task 6).
