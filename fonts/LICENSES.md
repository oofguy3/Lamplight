# Bundled fonts

Every family in this folder is licensed under the SIL Open Font License 1.1; the full licence text is in `OFL.txt`. Only the Latin subset of each family is bundled, and a family is fetched the first time a reader chooses or previews it (see `FONTS` and `Fonts` in `app.js`); the service worker then keeps it for offline use.

The `.woff2` files other than Atkinson Hyperlegible are the ones published by [Fontsource](https://fontsource.org/) — package `@fontsource/<name>` for static families and `@fontsource-variable/<name>` for variable ones, all at version **5.3.0** — and the copyright lines below are those of each package's `LICENSE` file.
